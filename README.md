# 简历措辞检查（Resume Wording Check）

投出去之前过一遍：**哪些话没有依据、哪些是空话、哪些成绩自己都证明不了**。

两层检查叠在一起：
- **词库层**：59 条中文简历高频问题词（空话 18 / 绝对化 15 / 模糊出处 14 / 奉承 12），逐句标出并给改法；
- **结构层**：自动识别简历类型（职场 / 应届 / 零实习），按简历诊断规则做结构诊断（缺模块、缺量化、描述要点缺失），并给出六维近似评分。

单文件网页 · 零依赖 · 完全离线 · **你粘贴的文字不上传**

---

## 快速开始

- **在线用**：打开在线版：<https://everstoneai.github.io/resume-wording-check/> ，点开即用。
- **本地用**：下载 `index.html`，双击用浏览器（Chrome / Edge 等 2018 年后的版本）打开。无需安装、无后端、不联网。

使用流程：把简历文字整段粘进来 → 点「开始检查」→ 上方看词库命中，最下方看「结构诊断 + 六维评分」→ 按「改写指南」逐条改。

## 它检查什么

**词库层（四类，逐句标出 + 改法）**

1. **没依据的话**：绝对化断言（精通 / 遥遥领先）与模糊出处（据说 / 广受好评）——改成「范围＋数字」；
2. **空话套话**：认真负责 / 吃苦耐劳等——删掉，换成一件具体的事＋结果；
3. **顺着你说的话**：恳请贵公司 / 不胜感激——直接删；
4. **长句**：超 60 字拆成两三句。

**结构层（规则近似，仅供参考）**

- 自动识别简历类型：职场人士 / 应届生（有实习）/ 零实习；
- 缺模块提醒：按类型查模块组合（如应届=实习＋实践＋专业技能），缺哪个报哪个；
- 描述要点：12 类经历描述的关键骨架检查——做了什么＋量化结果、项目三层面、自我评价不少于 3 条、职业规划短中长期等；
- **六维近似评分（满分 100）**：简历完整度 20 / 经历描述 50 / 学习能力 15 / 专业能力 5 / 创新领导力 5 / 职场能力 5。

**配套内容**：改写指南（查出问题后怎么改、数字素材从哪找）、AI 改写提示词（一键复制，带防编造约束）。

## 它不做什么（边界）

- 只标记与提醒，**不判断简历好坏**：工具从不说"这份简历不行"，定性留给人；
- 结构诊断为**确定性规则近似**（非 AI），存在漏报误报，页面上有标注；
- 不代写简历、不承诺任何求职结果；评分仅供自查参考，不代表任何招聘结果。

## 隐私与安全

- 所有检查在你本机浏览器完成，文字**不上传、不联网、无统计埋点**；
- 代码就 `index.html` 一个文件，无构建、无依赖，全部逻辑可直接审阅。

## 自测

地址后加 `?selftest=1`：自动填入探针句并跑词库检查，页面顶部黑条显示各类命中数（全 0 才说明坏了）。实测记录见 [docs/selftest.md](docs/selftest.md)。

## 已知边界

- 结构诊断基于**纯文本近似解析**：模块标题（如"实习经历"）需独占一行才能被识别；
- 描述要点为关键词＋句式近似，有漏报误报；经历描述一维按规则通过率折算，不是 AI 评分；
- 复制改法清单目前只含词库层结果（结构诊断后续可加）。
